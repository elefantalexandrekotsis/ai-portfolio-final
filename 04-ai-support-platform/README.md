# AI-Powered Support Platform
Full-stack chatbot with escalation detection and analytics.
## Stack
Next.js, FastAPI, OpenAI, PostgreSQL (pgvector), Redis, Docker
## Quick Start
    cp .env.example .env
    docker-compose up -d
Frontend: http://localhost:3000
API docs: http://localhost:8000/docs
## Features
- Real-time AI chat
- Auto-escalation to human agent
- Analytics dashboard
- Cost tracking per conversation
